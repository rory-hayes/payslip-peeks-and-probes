## Findings

### BUG-001 — UK demo mixed GBP and EUR in one journey

- Severity: **Major**
- Status: **Fixed and regression-tested**
- Surface: demo dashboard, year-to-date summary/chart, and PDF export
- Reproduction:
  1. Open the public landing page and choose **Try the demo**.
  2. Compare the latest payday and pay-history amounts with the year-to-date summary and cumulative table.
  3. Export the sample PDF while the signed-out profile currency fallback is EUR.
- Actual before fix: payday/history used `£`, year-to-date figures used `€`, and PDF metadata inherited the signed-out profile fallback.
- Expected: the whole sample story is UK/GBP because every sample payslip is a UK payslip.
- Customer impact: damages trust in a product whose primary promise is pay accuracy and could create a misleading exported record.
- Root cause: the year-to-date components read profile currency internally while the rest of the demo used a journey-specific formatter. Two sample rows also lacked explicit GBP metadata.
- Fix:
  - pass the journey currency formatter and symbol into both year-to-date components;
  - mark every demo payslip as GBP;
  - force the read-only PDF sample to UK/GBP;
  - standardise the demo formatter to two decimal places.
- Verification:
  - mobile rendered output now contains GBP-only YTD figures, including `£11,250.00` gross and `£8,405.00` net;
  - regression tests prove that an explicit journey currency overrides an unrelated EUR profile fallback and that PDF input is UK/GBP.

## Tax Helper Review

- Ireland uses a calendar year; the UK uses 6 April to 5 April.
- The default review period is the last completed year, avoiding premature refund prompts during an active tax year.
- Both country paths use only Revenue or GOV.UK destinations and state that Payslip Insights neither decides eligibility nor files a claim.
- Ireland topics cover Rent Tax Credit, unreimbursed health costs, Flat Rate Expenses, and pension/AVC relief.
- UK topics cover employee expenses, pension relief, Marriage Allowance, and Gift Aid.
